# KuroVia Mail – Installationspakete

Mail, Kalender und Kontakte für Ubuntu 22.04 und neuer. Hier liegen nur die fertigen Pakete.

## Installieren

1. [kurovia-mail_amd64.deb herunterladen](https://github.com/Elisabeth-KuroVia/kurovia-mail-releases/releases/latest/download/kurovia-mail_amd64.deb)
2. Doppelklick auf die Datei → „Installieren“ – oder im Terminal:
   `sudo apt install ./kurovia-mail_amd64.deb`
3. „KuroVia Mail“ im Startmenü öffnen.

## Updates

Die App meldet neue Versionen selbst (unten in der Seitenleiste). Ein Klick auf
„Jetzt aktualisieren“, einmal das Passwort eingeben – fertig.
